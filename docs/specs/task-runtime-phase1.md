日期：2026-10-15。LF 已确认一期解决长程运行，二期可视化，三期价格优化；已授权实施及独立开发环境部署。现有 DSH 实例定义为生产。LF 后续明确允许数据分开：开发使用独立 DSH_HOME、profile、sessions、storages、附件与项目执行资料，不能与生产共写运行存储。

## 目标与边界

A²D² 在宿主后台管理已明确启用的任务运行。主会话身份、接续和事件投递由插件维护，模型处理任务内容并提供交接内容。浏览器关闭或开发实例更新后，执行状态仍可追踪和恢复。任务的目标、需求与验收仍以 tracker 为准，插件只持久化执行状态。保持已有普通会话与手动交接行为；不自动接管已有生产任务。

本期包括：受控启停、主会话执行权、自动接续、上下文阈值交接、工作空间继承、任务事件收件箱、交接中断恢复、真实 DSH 开发部署。排除：新仪表盘/会话树、成本路由、价格优化、自动合并 PR、关闭 GitHub issue、清理或停用现有生产监督脚本。

## 执行语义

- 为已绑定 issue 的任务显式启用后台运行，记录项目、任务、workspace、当前会话、运行状态、交接步骤与后继 ID；提供启动/暂停/恢复/状态/请求交接能力。普通 `bind_main_session` 仍保留兼容，但不等于已启动无限自动运行。
- 每个任务只有一个有效执行者。交接必须等待源会话的安全空闲边界，持久化预定后继 ID，再创建或恢复该后继。已有任务记录与运行记录必须一致；过期源会话不能继续作为主控执行。不得杀死无关会话或重启生产。
- 后台统一驱动 prepare → 等待有效交接文档 → 同工作空间创建/恢复后继 → 设置会话本地 Agent 模型 → take/接任 → 投递待处理事件。调用宿主公开 API，禁止写宿主私有 registry 或直接修改服务持有的存储文件。
- 运行中的任务在一轮结束后检查完成、等待人、等待子任务/外部事件以及可继续状态。完成和明确等待不能被盲目续跑。自动重试有限、故障原因持久化可查询；没有进展不能假装成功。
- 事件以任务为接收者；持久化后投递给当前有效主会话。PR 事件与子任务完成需接入该路径，交接期间保留事件。DSH 原生子代理完成路径必须明确覆盖或在未结算子代理存在时禁止换代，避免把结果送给过期主会话。
- 每次外部副作用记录恢复点；进程在创建、接任、投递间退出后重试不得重复创建后继或并行接管。不能保证绝对一次的外部边界必须以稳定事件 ID、日志回读/去重与可观察状态处理，不宣称不存在丢失/重复窗口。

## 验收

- Given 显式启用的任务，When 浏览器关闭且会话一轮结束，Then 后台依据状态接续，等待/完成不会空转。
- Given 上下文达到配置阈值，When 主会话空闲且无未结算子代理，Then 后台完成交接，workspace 正确，只有后继保有主控执行权。
- Given 交接进行中，When PR 或子任务结果到达，Then 事件被持久化并由接任会话收到，旧会话不被继续唤醒。
- Given 已创建后继或已接任但流程未结束，When 插件重载/进程重启，Then 恢复同一次操作，无第二个后继、无重复接管。
- Given 并发启用/接续或重试事件，When 操作竞争，Then 单一所有者与去重规则生效，失败可见。
- Given 生产仍有运行任务，When 部署/更新开发环境，Then 生产不重启、不接管生产任务；开发配置、存储、调度及验收项目执行资料与生产隔离。

验证至少包含连续两次交接、一次失败恢复、一次宿主重启恢复和交接中事件到达。真实页面验证使用 agent-browser，证据落 `docs/artifacts/task-runtime-2026-10-15/` 并发布 LogSeq。源码测试通过不能替代页面与宿主验收。任务分支提交推送、创建 PR，不合并。
