# 08 — 持久化持续接活、串行领取与暂停恢复

## Parent

主任务 [#120](https://github.com/a2d2-dev/dsh-plugin/issues/120)；本票 [#128](https://github.com/a2d2-dev/dsh-plugin/issues/128)。已确认并发布，执行标签 `ready-for-agent`。

## What to build

研发对选定项目的仓库筛选或项目视图开启持续处理，宿主持续发现候选、复用已有工作、原子领取并执行；当前 Task 验收完成后接下一项。关闭浏览器、来源断连或宿主恢复不丢失候选和领取身份；暂停只停止接新工作。

## Acceptance criteria

- [ ] 规则保存具体项目、来源与筛选快照、排序、方法、资源和启用状态；无“所有项目”范围。视图修改若扩大授权范围，需显式更新规则。
- [ ] 发现和同步使用确定性适配，不调用模型询问是否有任务；分页游标、来源版本、候选和已处理事实可恢复。
- [ ] 重复发现、乱序事件和已存在子 Issue 先解析唯一映射；已有受管工作复用，不复制 Task 或重复启动。
- [ ] 首期一个规则至多一项正在自动推进；可推进槽位与Task协调资格分开。等待人类/评审/结果时到安全边界让出槽位，保留任务、owner和会话，继续下一合法项，不阻塞整个来源。
- [ ] 回复/结果先持久化并将等待项置为ready，再按串行规则重获可推进槽位；不得从事件投递绕过调度并发门槛。人主动暂停须显式resume；记录为何待恢复或尚未让出。
- [ ] 两个消费者、重复启用、并发点击、暂停与 claim 竞争由版本化领取决定；固定启动身份贯穿回执未知与恢复。
- [ ] 暂停接新工作不停止当前会话；用户若要求停止执行，使用独立操作并准确反映在途工具状态。
- [ ] 等待时安全让槽、验收完成后退出规则；Issue 关闭待同步不阻止接下一项，也不再次驱动已完成任务。
- [ ] 来源不可用保留已有内容/候选/当前执行，恢复后续接游标并去重；队列、Task inbox 和外部同步 outbox 各自职责可辨。
- [ ] 控制面板显示规则范围、当前项、待处理原因、暂停/恢复和失败重试；关闭浏览器后仍能从宿主事实恢复观察。
- [ ] 行为测试覆盖分页中断、重复/迟到、并发领取、启动已成功但回执丢失、等待、完成及同步失败；真实隔离宿主端到端证明连续完成两项且无重复执行。

## Boundaries and evidence

不开放多项目范围、多机分布式领取、多个自动推进槽或未授权范围扩展；允许多个等待项保留各自协调关系。PR评审会话票不是本片前置。自动 token 接续是可组合能力，但不是领取算法的前置；完整发布验收再组合自动接续切片共同验证长程场景。
