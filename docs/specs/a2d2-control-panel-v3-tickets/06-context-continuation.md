# 06 — 可配置上下文接续与历史会话观察

## Parent

主任务 [#120](https://github.com/a2d2-dev/dsh-plugin/issues/120)；本票 [#126](https://github.com/a2d2-dev/dsh-plugin/issues/126)。已确认并发布，执行标签 `ready-for-agent`。

## What to build

研发在项目/工作中配置提前接续目标，看到当前真实会话的计量及接续状态。达到目标后在安全边界固定后继并继续同一 Task，当前入口更新，旧会话进入只读历史；中断后恢复同一交接操作。

200K／300K 是软目标，不是任意模型的硬窗口保证。复用 02 已按新身份完成的手动接续与恢复原语；本片增加计量、策略、自动触发与观察，不把近似 UI 投影当预算权威。

## Acceptance criteria

- [ ] 保存项目默认及执行有效策略版本；设置明确单位和自动开关。200K/300K 依据实际模型能力校验，不固定假设 400K 容量。
- [ ] 使用公开 token measurement、真实路由和模型元数据，记录计量来源/日志版本、有效窗口、输出预留和交接余量。
- [ ] 按总规格预算状态表处理：已知窗口/输出/余量且新鲜的 estimated 可软触发但标估算；陈旧读数先重测；缺关键元数据暂停该Task普通自动turn并保留查询、修正策略和手动接续；恢复信息后回ready，人主动暂停不自动恢复。
- [ ] 新目标合法且低于当前计量时安排下一安全边界接续；换小模型使组合不可容纳时显示重验与可选上限。手动接续不能被自动预算守卫循环拒绝，实际材料生成失败仍保持可见受阻。
- [ ] 轮末或其他已证明的安全维护边界执行接续；等待人类或相关原生子执行时显示待安全接续，不能硬切断在途副作用。独立子 Task 的存在不自动阻止换代。
- [ ] 目标、规格、具体确认、证据、待办、下一步与必要本地引用进入后继；连续两次接续仍能恢复这些内容。
- [ ] 固定后继及操作身份贯穿准备、写作消费、创建、接任、事件投递；任一点失败后恢复不生成第二个后继或重复协调权。
- [ ] Task、Agent、Execution 与 Stage 保持；主指针只在有效接任后更新，历史与评审关系不抢占当前入口；旧会话不能继续推进原 Task。
- [ ] 界面“会话”表格显示段次、状态和可展开接续摘要；可查询历史，返回详情保留上下文。
- [ ] 合同测试覆盖长 turn、大工具结果、缺读数、换小窗口、压缩后下降和安全边界阻塞；真实宿主/模型验收单列，不把手工写摘要的 fixture 当语义质量证据。
