# 09 — PR 目录、工作关联与真实评审会话

## Parent

[A²D² v3 开发规格草案](../a2d2-control-panel-v3.md)。发布前草案；计划标签 `ready-for-agent`。

## What to build

研发在所选项目读取 PR 目录和检查结果，关联到既有 Task 或显式接入本地工作，进入真实评审会话，再回到 Issue／工作详情。评审会话保留自己的用途与结果，不能替代当前处理会话。

这一片独立于 Project views：即使没有 GitHub Project，仓库 PR 也可查询和评审。

## Acceptance criteria

- [ ] PR 列表/详情包含标题、正文、关联 Issue、检查、评审和远端状态，限定所选项目的仓库来源并支持分页/权限/离线观察。
- [ ] PR、关联 Issue／本地工作和 DSH 会话可以双向跳转；会话内的关联入口回到正确 Task，保留原生对话和输入框。
- [ ] 无关联 Task 的 PR 仍可只读查看；评审前显式选择已有工作或接入本地 Task，不伪造 Issue，也不隐式新建重复任务。
- [ ] 创建或复用评审会话使用 Task+PR+用途的幂等关联，显式继承资源、项目 Agent 策略及后端能力；重复点击和回执丢失不创建多个评审会话。
- [ ] 评审列在“其他关联会话”，不改当前协调会话或夺取执行资格；PR 检查通过、评审返回不自动完成 Task。
- [ ] 本片提供评审结果的持久记录/查询入口和稳定结果引用，不只停留在聊天文本里；07 的证据命令可引用该结果，但本片不调用尚未交付的验收命令，也不直接保存 Task 验收通过。
- [ ] 已知 PR watch 事件更新最后观察，重复/迟到版本不倒退；watch 不可用不阻断目录读取，状态刷新能力和错误明确。
- [ ] 固定响应包含有/无 Issue、多个关联工作、失败检查、过期事件和来源拒绝；真实宿主浏览器验证三向导航、复用和当前主指针不变。
- [ ] 真实来源补只读 smoke；本片不自动合并、关闭或重开 PR。

## Blocked by

- 02 — 单项工作启动、当前协调会话与执行资格。
- 04 — GitHub Issue 来源、唯一接入与本地内容保留。

## Boundaries and evidence

不依赖项目视图票，不阻塞仓库/Project来源的持续接活。可复用现有 PR watch，但不能把仅有状态推送当作完整目录/评审接口。未交付完整验收命令前，证据可以可靠记录和查询，但不得伪称 Task 已验收完成。
