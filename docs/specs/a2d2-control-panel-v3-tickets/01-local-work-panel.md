# 01 — DSH 单入口、本地项目与工作详情

## Parent

[A²D² v3 开发规格草案](../a2d2-control-panel-v3.md)。本文件是 GitHub 发布前草案，确认后作为新主任务的子 Issue；计划标签 `ready-for-agent`。

## What to build

用户在原有 DSH 中打开唯一的 A²D² 控制面板，选择具体领域项目，创建无 Issue 的本地工作，查看紧凑详情并关联／进入真实已有会话。首片同时落地最小稳定身份和本地记录；不能只交付静态列表，也不能要求 GitHub 或在线会话才能浏览。

项目从既有宿主资源渐进接入或独立创建，拥有自己的 ProjectId；Task 记录目标、规格、验收标准和所属项目。负责 Agent 使用项目默认策略建立稳定身份，不新增必经的 Agent 管理步骤。此片的会话关联是观察关系，不自动授予协调权或启动模型。

## Acceptance criteria

- [ ] 原 DSH 项目、会话、输入框与工具区保留；新增入口使用公开主内容插槽，关闭面板返回原会话。
- [ ] 项目下拉无“所有项目”；无项目时显示接入/创建入口，选择项目不创建 DSH 空会话、不发送模型消息。
- [ ] 无账号、无 remote、无 Issue、无在线会话时，仍可保存并重载 Project/ProjectAgent/Task 的独立身份、完整目标/规格/验收。
- [ ] Task 创建、规格更新、工作拆解与父子关联提供真实可调用的领域命令/模型工具，以父 TaskRef 创建无 Issue 子任务；有 commandId、版本和权限校验，同名或并发创建不覆盖其他记录。资源与 ProjectId 分开。
- [ ] 工作详情采用概览、会话、相关工作、活动标签；只显示当前项目内容；返回列表保留项目、视图与筛选。
- [ ] 可将兼容的已有 Session 作为关联会话并通过真实宿主导航打开；重复关联幂等，关联动作不改其 cwd、模型或权限，也不启动任务。
- [ ] 已关联的原生会话有轻量工作/进展入口，能返回正确 Project/Task 的四标签详情；未关联会话不增加必经步骤。浏览器验证来回导航及返回位置。
- [ ] 通过统一工作命令/查询接缝验证重载后数据完整；通过真实隔离 DSH Web 与禁用模型适配验证入口、导航和零意外调用。
- [ ] 新记录版本与旧 writer 隔离。建立后续迁移所需的唯一旧地址映射契约；本片不复制活动旧任务再自动启动。

## Blocked by

None — can start immediately。

## Boundaries and evidence

不包含 GitHub 来源目录、自动执行、活动旧记录迁移、自动接续或外部写入。提交时附真实宿主构建/插件能力基线、公共接口行为测试与浏览器证据；独立原型截图不能代替此片验收。存储技术选择是实现细节，但必须证明原子唯一性与单一写入契约。
