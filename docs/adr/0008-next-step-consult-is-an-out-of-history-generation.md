# 下一步咨询保持可选，查询状态不依赖模型生成

**状态：当前目标决策。** 用户需要随时知道工作和会话的真实状态。控制面板直接展示记录事实；需要方法建议时，可以使用不写入工作对话的一次性咨询。

## 决定

- Issue／Task 进展、当前协调会话、接续历史、PR 检查、来源连接和同步状态来自各自权威记录或最后观察，不为了打开详情而调用模型。
- 下一步咨询是可选的宿主侧一次性生成，不创建持久子会话，也不代替当前 Task 的负责 Agent 接管工作。咨询失败不使工作列表或状态查询失效。
- 咨询素材来自当前 Task、已接受事实、真实会话上下文和项目选用的方法。既有 Matt 咨询可保留自己的结构化输出契约，但该契约不定义全部项目的工作方式。
- 生成结果是建议，不能直接提交业务阶段、验收完成、负责人变更或执行授权。采纳建议后仍进入对应命令与校验路径。
- 如咨询使用候选回退，结果保留实际调用路由与失败原因；不通过回退修改当前会话模型或 DSH 全局默认值。
- 可选咨询不要求 GitHub，不能用“先读取 Issue”作为所有本地任务的通用前置。

## 实现覆盖

已有宿主侧咨询与模型候选回退能力可继续使用。当前控制面板的查询投影需新增领域记录和外部观察来源，不能用咨询生成的自由文本替代这些字段。
