# 显式意图授予作用范围内的自动化，不把浏览误当执行

**状态：当前目标决策。** 用户继续通过 DSH 对话和控制面板表达工作意图。明确的执行按钮或持续处理设置可以授权其标明的行为；浏览、查询与模型建议不自行取得执行资格。

## 决定

- 打开控制面板、切换项目／视图、查看 Issue／PR／历史会话不创建任务执行、不发送模型消息、不启动队列。选择 Project 不等于连接或创建 DSH Workspace 会话。
- “开始处理”是明确命令。系统在展示所用项目、工作、执行环境与有效策略后，可在这次授权范围内完成保存关联、申请资格和启动，不要求用户手工逐个操作底层对象。
- “持续处理”保存具体项目、来源筛选、执行方法、资源及调度范围。启用后只处理该范围内的候选；重复启用复用已有规则和执行，不重复接活。
- 暂停接新工作与停止当前执行分别表达。前者阻止新领取，保留当前工作；后者经宿主安全边界处理，不能把界面状态改成 paused 就声称工具或子进程已经停止。
- 自动接续由用户启用的策略授权，在已授权 Task 与执行资源范围内继承上下文。切换来源、查看历史或点击评审会话不扩展这份权限。
- 现有下一步候选芯片仍是建议入口：填入意图、准备新会话或展示交接材料，不以生成建议为由代替用户提交。明确标为执行命令的控制面板按钮使用自己的命令契约。
- 常规、可撤销且已经授权的推进不反复请求确认。超出授权范围、影响生产或不可逆的外部动作须单独获得明确意图；新任务内容不能自行扩大执行权限。

## 可观察结果

每次命令显示已接受、执行中、完成或失败；“请求已接受”不等于会话已启动或消息已消费。关联和执行可以编排在同一用户动作内，但失败后仍能辨认哪一步已经成立。

## 实现覆盖

现有候选芯片与受管运行器已有部分意图边界；控制面板命令和来源队列的授权范围属于本次目标。
