# 默认配置与项目策略分域保存，执行使用明确的有效快照

**状态：当前目标决策。** A²D² 复用 DSH 设置能力保存插件默认值，项目策略属于对应领域 Project。模型、接续和持续处理配置的改变不能泄漏到其他项目或宿主全局默认。

## 决定

- 插件默认值与可复用角色模板使用独立、带 schema 的设置命名空间；项目保存自己的策略与覆盖版本。ProjectId 是作用范围，不以当前浏览器会话 cwd 隐式决定。
- Project Agent 的候选路由、能力要求、工作流映射与指令配置遵循 ADR 0004。角色模板不是唯一的全局业务 Agent 集合。
- 接续策略支持项目默认与任务执行时的有效配置。用户可配置 200K、300K 等提前接续目标；必须结合实际模型窗口、输出预留、交接余量和计量可用性校验，不能固定假定模型都有 400K 容量。
- 用户阈值是软接续目标，不是单次请求或长 turn 的硬 token 上限。模型窗口未知、计量估算或路由变更时明确显示状态，不能展示未经证明的安全余量。
- 持续处理规则明确保存所选项目、来源筛选、方法和资源；保存设置本身不自动接管已有未授权任务，启用行为单独可见。
- 配置修改使用版本检查，执行记录保存有效策略身份。新建／接续时使用公开的会话本地配置，不修改 DSH 的全局新会话默认模型；恢复时尊重后续明确的用户改动。
- 启动／接续时的模型快照用于记录当时的选择，不是会话终身配置。用户在宿主切换 provider、模型或推理强度后，恢复读取当前有效的会话本地选择，并更新执行记录中的当前配置；历史请求继续保留各自实际采用的路由，不改写为新模型。尚未发起请求的新选择也有效，不能要求最新请求头先与它一致才能恢复。
- 当前选择改变时，按新模型重新解析可用性、能力、窗口与接续预算；重新校验成功后按原授权继续。默认值或候选列表的普通编辑不自动覆盖已有会话的选择，模型变化也不扩大有效权限或取消用户的暂停。
- 显式推理强度必须经精确模型元数据验证；无法验证时可见失败，不静默忽略。模型是否在目录、能否调用、能否承担所需执行能力分别观察。
- 设置读取和修改沿用宿主浏览器认证、请求边界与内容类型校验。浏览器只提交服务端可解析的 Project／资源引用，不携带来源凭据或任意宿主路径。
- 高级角色和模型设置放在适合的配置界面；控制面板主导航保持 Issue、PR、项目。无需在配置页首屏强制呈现整张方法论图。
- 模型探测只在明确的测试意图下执行；普通列表刷新、状态读取和源轮询不消耗模型调用。

## 实现覆盖

已存在插件设置命名空间、配置页和候选路由校验。项目策略、局部阈值和可靠计量校验仍需扩展；配置文档不能把已有全局 `rotateTokens` 宣称为完整的新策略。
