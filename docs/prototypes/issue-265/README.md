## 已确认的方向

- 当前 Project 只有一个持续委托队列和一份设置，不管理多条规则或多批次列表。
- 历史、正在处理、等待处理和需人工项同属这个队列；状态分类只是筛选。
- 点击更新或周期到来，仅重新筛选、排序等待部分，保留在途与历史；移出等待不删除 Project 中的 Task。
- 按并发上限推进，Task 结束后保留历史并补入下一项；会话问题只记录并交人处理。
- 队列只展示调度所需的顺序、Task 名称入口、处理状态和会话入口；任务详情与纠偏复用既有 Task／会话页面，不重复制作。

## 演示边界

所有数据和时间推进都在浏览器内存中，不调用真实 GitHub、模型或执行服务。底部“演示”按钮用于验证刷新、补位和问题处理，不属于正式产品功能。

Task／会话入口只记录跳转意图，正式实现必须接到现有详情、当前会话和历史会话导航。原型不提供另一套任务详情或人工纠偏表单。

原型里的占位计数、虚拟任务结果等用于说明交互，不能替代宿主实际运行状态、安全边界、执行资格或验收合同。
