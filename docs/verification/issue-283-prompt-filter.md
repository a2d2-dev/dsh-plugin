# 持续委托定时任务提示词筛选验收

## 目的

在既有定时扫描中，标签、负责人、开放状态先产生候选，再将整批候选与用户提示词进行一次大模型筛选，匹配结果进入原委托队列。

## 步骤与记录

- 在最新 main 上实现多行提示词的保存、回读和清空。整批候选只调用一次模型，包含完整正文，支持候选之间的比较条件。每次定时或手动刷新都重筛当批候选。
- 6 个相关测试文件共 87 项通过。覆盖 25 项候选单次筛选、下一定时周期 26 项候选重筛、错误和缺项不放行、提示词/正文变化、慢模型期间已有任务继续维护、真实 DSH Session 的现有持续执行与接续行为。前后端类型检查与构建通过。
- 独立只读复核发现模型等待可能阻塞全局维护和来源刷新锁；已将模型调用移到来源锁外，定时路径独立追踪模型请求，相关复现回归通过。单次模型调用超时两分钟。
- 现有 GUI 使用正式插件生命周期热重载，新工作挂载 `a2d2-work-prompt-283-f35d978` 为 active，旧工作挂载禁用，宿主未重启。前端整合并保留现有 canvas 功能，构建成功后更新客户端资源。
- 部署备份和哈希保存在忽略的 `docs/artifacts/prompt-filter-2026-10-26/`。截图在同目录，GUI 操作只检查提示词输入，不启用队列。

## 边界

自动测试验证模型适配器及调度合同；本次没有对用户真实工作队列提交试验提示词或启动真实任务。使用时在「持续委托 → 设置 → 大模型筛选提示词」输入条件并保存即可。
