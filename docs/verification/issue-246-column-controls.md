# Issue #246：列头交互与搜索验收

## 目的与边界

对应 [Issue #246](https://github.com/a2d2-dev/dsh-plugin/issues/246)。在 Project、Issue、PR 表格提供统一的列头菜单和可见搜索框，保留真实来源、视图、分页、权限与 canonical Task 入口。列操作仅改变客户端展示，不创建处理会话、不启动持续处理、不写 GitHub 业务字段。

基线为 `origin/main` 的 `8198228`，独立分支 `feat/246-column-controls`。没有创建子任务；实现与验收均属于原 Issue。

## 行为

- 每列提供 `⋯`，支持选择整列、升降序、真实值多选过滤、隐藏恢复、左移／右移／首尾移动。基础标题列保留条目入口；边界和不支持的能力置灰并提供原因。
- Title 提供实际适用的类型／状态过滤。负责人、标签、单选等离散列提供分组和切片。同列多个值为 OR，多列与搜索为 AND。多值条目可出现在多个组；分组计数明确限定在当前展示页。
- 查询键使用观察到的原始值：日期保留年份与时间，文字 `—` 保留其真实含义；部分读取及权限受限的值明确归为“未观察到字段值”，区别于确认空值。没有观察到的字段类型不能排序或过滤。
- Project 搜索当前保存视图、入口切片与含关闭设置下的完整扫描快照；PR 搜索当前目录并说明完整性，两者在本地分页前查询。Issue 的列搜索／排序／分组／切片／过滤限定于当前载入页，来源搜索使用独立表单。
- 来源、视图和远端 Issue 查询页的身份是展示状态边界；切换后重建不适用状态，原有响应 revision 保护继续生效。移除可选列时清理失效查询状态。目录或保存视图不可读时保留搜索入口和原因，不能用整个 Project 快照代替该视图。
