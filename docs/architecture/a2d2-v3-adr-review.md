## 复核结果

独立只读复核确认：强制 Task=Issue、Project=cwd、全局固定三位 Agent、主会话必为 CEO、只读会话侧栏为唯一入口等旧规范已移除；目标与实现覆盖分别说明。

复核发现一处缺失的不变量：两个不同 Task 可能同时合法占用同一 Session。现已在 ADR 0011 明确首期 Task/Session 双向唯一性；共享协调会话须有任务寻址、会话级有序驱动和集合交接能力后才能开放。

token、原生子会话和独立子 Task 的边界已经核对：200K/300K 是软目标；无计量或陈旧计量不能假报安全；未结算原生子执行可能阻止安全接续，但独立子 Task 的存在不自动阻止交接。

本轮采用文档一致性、相对链接和代码差异检查；未运行产品测试、启动真实任务或操作现有服务。完整实现证据见[能力核查](a2d2-v3-implementation-evidence.md)。

开发规格和票据又经两个独立视角复核。等待让槽、TaskId 控制/手动接续原语、token 退化表、本地子任务/证据写入、会话反向入口及来源对象分流均已收紧；项目视图与 PR 评审拆为独立票。最终 9 票的正文、索引图和发布清单具有一致的 11 条依赖边，无环，初始 frontier 只有 01。局部链接和被替换旧文件的移除检查通过。复验没有剩余重要问题，但这些是规格检查，不是尚未实现能力的产品验收。
