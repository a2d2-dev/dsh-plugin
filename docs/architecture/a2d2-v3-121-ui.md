# #121 控制面板 UI 与验收说明

## 背景

旧入口位于会话右侧 tab，旧查询由 live Session/cwd 寻址，不能承担独立领域 Project/Task 浏览。本票使用已确认的 DSH 公开插槽与工作应用接口。原型仅作交互证据，产品代码重新按接口实现。

## 目标与非目标

目标是单入口、具体项目、无 Issue 本地工作详情与原生会话往返。GitHub 来源、自动运行/接续与活动旧任务迁移不在本票实现范围。

## 架构

- `src/client/index.tsx` 向 `sidebar.panellist` 增加 `a2d2-panel`，向 `main` 注册同名 key，保留 root/sidebar/conversation。插件包图与服务注入声明 layout/uiWorkspace/remote workspace 依赖。
- `WorkPanelController` 在插件根生命周期中保存列表位置。项目选择只调用工作查询；关闭面板调用 `layout.selectPanel(null)`；打开已有 Session 调用 `uiWorkspace.openSession`。
- `work-api.ts` 通过同源认证 POST `/a2d2/api/work`，使用 `src/work-types.ts` 的纯类型合同。错误保留后端 code/message，不使用静态产品数据或本地 fallback。
- 会话标题操作插槽查询受权资源的 runtime 引用，再读取 `session.work`。无关联返回空渲染；关联入口返回精确 TaskRef。领域记录来自后端，不依赖 live Session。

数据走向：宿主插槽 → 工作面板/控制器 → 受信任 HTTP 工作命令查询 → 后端本地记录；已有会话导航独立交给宿主。

## 场景

### 接入与关闭

安装插件 bundle 后，原 DSH 侧栏增加“A²D² 控制面板”。打开后查询具体 Project；关闭回到原会话。无 Project 时应提供接入已有资源/创建本地项目入口。项目切换不调用 connectWorkspace、不创建 Session、不发 prompt。

### 浏览与返回

选择 Project，在本地视图中搜索工作，进入详情，返回时保留 Project/视图/搜索；换项目清理旧条件。已关联会话通过宿主 openSession 打开，标题的工作入口回到同一 Project/Task。

### 失败与恢复

HTTP 非 JSON、认证失败、版本冲突和传输异常显示真实错误；不显示假成功。写命令带 commandId 与后端版本条件；冲突后重新读取记录，不能覆盖别人的提交。
