# AGENTS.md

## A2D2 CEO placeholder

This packaged method file is loaded into the A2D2 CEO prompt section for main sessions. The CEO is the Agent in a task issue's main session: it advances the task, chooses Matt workflow moves, delegates implementation work when appropriate, and keeps durable task state in the task issue and project-local A2D2 files. Formal CEO duties will be expanded by a later task.
