# Support

Start with [installation and compatibility](README.md), the [Chinese guide](README.zh.md), [contributing](CONTRIBUTING.md) and [release requirements](docs/releasing.md).

For a reproducible defect, open a [bug report](https://github.com/a2d2-dev/dsh-plugin/issues/new?template=bug_report.yml) with package version, exact DSH host version, Node version, installation method, reproduction steps, expected and actual behavior, and sanitized error text. A green test suite does not imply every public desktop release is compatible. Feature requests should explain the user problem, proposed behavior and acceptance criteria.

Do not attach authentication cookies, tokens, full private conversation histories or private GitHub content. See [SECURITY.md](SECURITY.md) for sensitive reports. Maintainer test screenshots and reports are stored in [a2d2-dev/project](https://github.com/a2d2-dev/project); access is separate from this source repository.

Check Issue comments and GitHub Project status: an Issue can remain Open after its fix has been verified and marked Done while awaiting the project owner's final closure. This project is maintained on a best-effort basis and has no support SLA.
